# 🔎 Telegram Tender Bot

Telegram-бот на Python для автоматического поиска и фильтрации тендеров.

Проект разработан как рабочий прототип для автоматизации поиска закупок по заданным ключевым словам и регионам.

## 🚀 Возможности

- поиск тендеров по ключевым словам;
- получение данных из внешнего источника;
- фильтрация результатов;
- выбор региона поиска;
- поиск по всей России;
- исключение неподходящих закупок;
- вывод результатов непосредственно в Telegram;
- постраничный просмотр результатов;
- управление через кнопки Telegram-бота.

## 🔍 Примеры поисковых запросов

Бот может выполнять поиск по таким направлениям, как:

- охрана труда;
- обучение по охране труда;
- пожарная безопасность;
- профессиональная переподготовка;
- повышение квалификации;
- образовательные услуги.

## 🌍 Работа с регионами

Пользователь может выбрать:

- вся Россия;
- отдельный регион.

В тестовой версии реализована отдельная фильтрация для Кемеровской области.

## ⚙️ Как работает бот

1. Пользователь запускает Telegram-бота.
2. Выбирает регион поиска.
3. Запускает поиск.
4. Бот получает данные о закупках.
5. Выполняется фильтрация по ключевым словам и заданным условиям.
6. Неподходящие результаты исключаются.
7. Подходящие тендеры отправляются пользователю в Telegram.
8. Результаты можно просматривать постранично.

## 💼 Что демонстрирует проект

Проект демонстрирует навыки разработки Telegram-ботов, работы с внешними источниками данных, API, фильтрацией информации и автоматизацией поиска.

Подобную архитектуру можно использовать для:

- автоматической отправки найденной информации в Telegram.
